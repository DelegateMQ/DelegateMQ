◆ Receive()

ThreadMsg * dmq::os::ZephyrDelegateQueue::Receive ( k_timeout_t waitOption)
inline

Receive a message pointer, blocking up to 'waitOption'. The high-priority queue is always checked – and drained – first, so a pending HIGH message is returned even if NORMAL messages arrived earlier. Uses k_poll() to block efficiently on both queues at once rather than polling in a loop.

Returns
the message, or nullptr on timeout.

◆ Send()

bool dmq::os::ZephyrDelegateQueue::Send ( ThreadMsg * msg,
bool highPriority,
k_timeout_t waitOption )
inline

Send a message. 'highPriority' routes to the high-priority queue, which Receive() always drains first; otherwise the normal queue. 'waitOption' is K_NO_WAIT for non-blocking, K_FOREVER to block forever, or a finite k_timeout_t for a bounded wait – applied only to the one queue the message is routed to (each lane has its own independent capacity; there is no combined-depth wait across both).

Returns
true if the message was enqueued.
