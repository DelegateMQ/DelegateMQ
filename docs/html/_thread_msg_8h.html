Detailed Description

A class to hold a platform-specific thread message that will be passed through a dmq::os::Thread port's OS message queue.

See also
https://github.com/DelegateMQ/DelegateMQ David Lafreniere, 2026.

Identical across every dmq::os::Thread port (FreeRTOS, ThreadX, Zephyr, CMSIS-RTOS2, stdlib, Win32) except Qt, which dispatches via Qt's own signal/slot queued-connection mechanism instead of a ThreadMsg wrapper – kept as a single shared file here instead of one copy per port directory.
