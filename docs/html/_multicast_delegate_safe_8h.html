 Snapshot the current delegate list under lock, into smallBuf (up to smallCap entries) or largeBuf if there are more than smallCap. Returns the number of delegates snapshotted. The lock is released before returning, so the caller can invoke each delegate without holding it (see the comment on MulticastDelegateSafe::operator() for why). Non-templated: entirely independent of the owning container's signature.
