Detailed Description

Move-only subscription token. Internal implementation detail of Signal. Users should store ScopedConnection, not Connection directly.

Stores two type-erased shared_ptr<void> contexts (signal state and delegate copy) plus a raw DisconnectFn function pointer. No std::function heap allocation.
