void dmq::detail::DispatchAsync ( std::shared_ptr< IThreadInvoker > invoker,
IThread * thread,
Priority priority,
Args &&... args )

Builds the heap-copied argument message and dispatches it to thread.

Templated only on Args..., not on the owning delegate's target-object or return type, so this single instantiation is shared by every DelegateXAsync<...> signature that takes the same arguments, instead of each owning class generating its own copy of this logic.

Parameters
[in]invokerThe already-cloned delegate to invoke on the destination thread, type-erased through IThreadInvoker.
[in]threadThe destination thread, or nullptr if unbound.
[in]priorityThe message priority.
[in]argsThe function arguments, if any.
