Detailed Description

Timer-safe async delegate. Connects a periodic timer to a thread dispatch with built-in queue-flood prevention.

Implements Delegate<void()> directly so it can be stored in Signal connections without a DelegateFunction wrapper – eliminating the std::function layer on the hot path.

At most one message is in the target thread's queue at any time; excess timer ticks are silently dropped rather than accumulated as backlog.

Prefer constructing via MakeTimerDelegate() rather than directly.

Note
Not intended for concurrent invocation. Safe when operator() is called from a single ProcessTimers() context.
