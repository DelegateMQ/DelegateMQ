Detailed Description

template<typename Transport, size_t MaxPeers = 4, size_t MaxTopics = 16>
class dmq::databus::NetworkNode< Transport, MaxPeers, MaxTopics >

Generic multi-peer DataBus network node.

All member functions are safe to call before Start() or AddPeer(); registrations are stored and applied when the relevant participant is created.
