Detailed Description

Non-templated: the mutex + alive-flag + delegate list shared by every Signal<Sig> in the program. Hoisted out of Signal<Sig> (where it lived as a nested State struct) because nesting inside the class template caused a separate (byte-identical) type – and critically a separate xmake_shared allocation control block – to be generated per signature, even though none of its members depend on RetType/Args.
